    Arabic and Latin input are both accepted. Matches ignore accents, hamza forms and diacritics.

    Contribute your votes

    Tapped ✓ / ✗ on rows above? Send your decisions back to the repo: they are appended to FuzzyMatch/votes.csv through a pull request, so everyone's votes accumulate for the next matching round.

    You'll need a GitHub personal access token (fine-grained, with Contents and Pull requests set to read and write on EbrahimKaram/Lebanese-Villages-List). The token is used only inside your browser to call api.github.com — it is never sent anywhere else.

    How to create a token (takes ~1 minute)
    1. Open github.com/settings/personal-access-tokens/new (fine-grained token)
    2. Token name: village-votes; set an expiration (e.g. 30 days)
    3. Resource owner: EbrahimKaram
    4. Repository access → Only select repositories → pick Lebanese-Villages-List
    5. Under Repository permissions, set Contents to Read and write
    6. Also under Repository permissions, set Pull requests to Read and write (needed to open the PR)
    7. Click Generate token, copy it, and paste it below

    After vote PRs are merged, their tallies show up on the review rows above.

    Suggest matches

    Spotted the right pair in a search result or review row? Tap ✓ Select as match on any candidate — tap again to undo. Your picks are staged here, then sent to FuzzyMatch/suggested_matches.csv through a pull request (same token as above).

    After suggestion PRs are merged, they show up as 🤝 on the matching rows.
