    Contribute your votes

    Tapped ✓ / ✗ on rows above? Send your decisions back to the repo: they are appended to FuzzyMatch/votes.csv through a pull request, so everyone's votes accumulate for the next matching round. Anyone with a GitHub account can contribute.

    You'll need a GitHub personal access token — a classic token with the public_repo scope works for everyone; a fine-grained token works too, for collaborators (see both options below). If you can push to this repo your contribution goes in directly; otherwise the page forks the repo to your account automatically and opens the pull request from it. The token is used only inside your browser to call api.github.com — it is never sent anywhere else.

    How to create a token (takes ~30 seconds)

    Option 1 — classic token (recommended, works for everyone):

    1. Open github.com/settings/tokens/new
    2. Note: village-votes; expiration: 30 days (or longer)
    3. Tick public_repo — the only scope needed (vote, fork if needed, open the PR)
    4. Click Generate token, copy it, and paste it below

    A classic token can act on all your public repos — it never leaves your browser, and you can revoke it any time at github.com/settings/tokens.

    Option 2 — fine-grained token (collaborators only):

    1. Open github.com/settings/personal-access-tokens/new
    2. Token name: village-votes; expiration: 30 days
    3. Resource owner: EbrahimKaram
    4. Repository access → Only select repositories → pick Lebanese-Villages-List
    5. Under Repository permissions, set Contents to Read and write
    6. Also set Pull requests to Read and write (needed to open the PR)
    7. Click Generate token, copy it, and paste it below

    Least privilege, but GitHub doesn't let fine-grained tokens open pull requests on repos you can't push to — so visitors without write access should use the classic token above.
